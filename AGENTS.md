# Fajr Parsa — AI / Agent Working Rules

## Mandatory global rule
Before material work, read and apply:
https://github.com/KAF-Business-Suite/openai-cloudflare-github-hub/blob/main/docs/GLOBAL_PROJECT_AI_GOVERNANCE.md

Then recover the current Fajr PR/issue, deployment evidence and KAF shared-core boundary.

- Do not create a duplicate source of truth when KAF already owns shared platform data/policy.
- Re-run the global five-stage mini-gate for material provider, architecture, Auth, data, URL, security, cost, automation or deployment changes.
- Safe read-only/reversible continuation proceeds without repetitive approval.
- Ask only for genuine ambiguity, destructive/irreversible work, cost, credentials, production/customer/financial/external-message changes, or two materially different undecided directions.
- Build/deploy is not real mobile/auth/business acceptance.
- Keep customer data, credentials and secrets out of Git and prompts.
