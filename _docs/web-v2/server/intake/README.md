## Overview

This directory contains the server-side components and tests related to intake handling. At the root level there are test modules (for example, fp04-scenarios.test.mjs) that import a test harness from node:test, assertions from node:assert/strict, and the intake handler implementation from a local handler.ts file. The documented test file exercises intake handling logic by importing the handler implementation and running scenario-based assertions.

In addition to the documented test file, the directory also contains implementation and supporting files (listed but not documented here) such as handler.ts (the intake handler implementation), handler.test.mjs (additional tests), adapters.ts, pages-entry.ts, and a README.md. Together, the tests and the handler implementation form a small focused feature area: the intake logic is implemented in TypeScript (handler.ts) and validated through Node.js test modules that use the standard test/assert APIs. This directory plays the role of implementing and verifying intake behavior within the larger server application.


### File Organization

Files are organized around the intake feature: implementation (handler.ts) and related tests (fp04-scenarios.test.mjs, handler.test.mjs). Test modules at the root exercise the handler implementation. Supplementary files (adapters.ts, pages-entry.ts) are colocated to support the feature.
