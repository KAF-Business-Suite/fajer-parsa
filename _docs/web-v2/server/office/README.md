## Overview

The web-v2/server/office directory groups the server logic related to "office" request handling. At the root level it provides TypeScript modules that define adapter types and factory functions (adapters.ts) and the primary request handling logic with its types and runtime error classes (handler.ts). Accompanying those runtime modules are two test modules (adapters.test.mjs and handler.test.mjs) that exercise the adapter surface and the exported handler, respectively.

Together these files form the core of office-related request processing: adapters.ts supplies typed adapter constructs and factories used by the handler logic in handler.ts, while handler.ts exports an asynchronous entry point (handleOffice) and defines the specific types and runtime errors that callers and tests depend on. The test files in the same directory validate both the adapters and the handler implementation. There is also an untracked README.md present in the directory root (listed but not documented here). This directory therefore encapsulates both implementation and tests for the office server surface and is intended to be consumed by higher-level server code that dispatches requests into handleOffice.


### File Organization

Files are organized by feature: runtime implementation (handler.ts), supporting adapter definitions and factories (adapters.ts), and focused unit tests (adapters.test.mjs and handler.test.mjs). Implementation and tests are colocated to make it easy to change behavior and update tests together.
