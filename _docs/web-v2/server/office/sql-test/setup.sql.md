## Overview

This SQL setup script provisions a disposable CI database environment for the web-v2 office service. It creates three roles (anon, authenticated, service_role), an auth schema with a minimal users table, and a public table fajr_web_requests that stores incoming web request metadata (including service, destination, variant, contact, status, private_extra, and created_at). The script enables row level security on the fajr_web_requests table and revokes all privileges on it from public and the defined roles. It also sources an external SQL proposal file and inserts seed user and office member rows into the auth.users and fajr_private.office_members tables respectively to provide initial test identities and membership state.
