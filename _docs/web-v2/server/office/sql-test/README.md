## Overview

This directory contains a single SQL setup script (setup.sql) whose purpose is to provision a disposable CI database environment for the web-v2 office service. The root-level file establishes the database schema and any initial data or configuration required by CI jobs that run tests or other verification steps against the office service. There are no subdirectories in this folder; all setup logic for the disposable CI database is centralized in the setup.sql script.

Within the larger system, this directory's role is narrowly focused: it provides a reproducible and isolated schema/data provisioning step for continuous integration pipelines that need a database instance for the office service. CI jobs can reference this script to create or reset a test database before executing integration or system tests, ensuring a consistent environment across runs. Developers working on database-related changes for the office service should update this script so CI environments reflect those changes during automated runs.


### File Organization

All provisioning logic is kept in a single SQL file (setup.sql) at the root of this directory to simplify CI inclusion and to make the disposable database setup a single-step operation. No subdirectories are present because the directory's scope is intentionally small and focused on CI provisioning.
