## Overview

This directory groups code related to office-specific features of the web-v2 frontend. At the root level it includes a React workspace component (OfficeWorkspace.tsx) that defines types and the functional behavior for an office-related workspace in the application; a TypeScript module (office-gateway.ts) that exports a factory function createOfficeGateway to produce an OfficeGateway instance used for office-related cases; and a test module (office-gateway.test.mjs) that exercises the gateway implementation. Together these files represent the UI entry point for office interactions (the workspace component) and the underlying gateway implementation that the workspace or other consumers would use to perform office-specific operations.

There are no subdirectories in this folder. The layout is intentionally flat: UI behavior and the gateway implementation live side-by-side to keep office-specific logic localized. Tests for the gateway are colocated at the root of this directory so they are easy to find and run alongside the implementation.
