## Overview

This directory contains the source code for the web frontend: at the root it holds application entry points, global stylesheets, and build/type hints (filenames are listed but individual file purposes at the root are not documented here). The root-level files include App.tsx, main.tsx, several CSS files (base.css, index.css, mobile-polish.css, theme.css, visual-review.css) and a TypeScript environment declaration (vite-env.d.ts); these files collectively represent the app shell, styling, and build/type configuration used by the code in subdirectories.

The office/ subdirectory contains React/TypeScript UI components and type definitions focused on the office area of the application. At its root the documented OfficeQueue.tsx file provides TypeScript types and a React component that renders and manages an office queue UI and related workspace components for office-specific views. Other subdirectories (components, content, lib) are present at the src level and group feature components, content assets, and library code respectively, enabling the OfficeQueue and other UI pieces to import shared components and utilities. Together, root entry files, global styles, and the subdirectories form the front-end implementation surface for rendering the application and the office-specific interface elements.


### File Organization

Top-level root holds application entry points and global styles, while feature-focused code lives in subdirectories (office/ for office UI components, plus components, content, lib). This separates the app shell and styling from feature implementations and shared libraries.
