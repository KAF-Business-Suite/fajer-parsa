## Overview

This directory is the main source tree for the web-v2 frontend. At the root it holds application entry points and global styles: files such as App.tsx, main.tsx, and several CSS files (base.css, index.css, mobile-polish.css, theme.css, visual-review.css) plus type hints (vite-env.d.ts). These root files provide the application bootstrap, top-level React entry, and global styling used across the web app.

Under src there are feature and helper subdirectories. The office/ subdirectory groups office-related UI and logic: it contains a React workspace component (OfficeWorkspace.tsx) that defines types and runtime behavior for the office workspace, an OfficeGateway implementation and its tests for office-specific functionality. Other subdirectories present at this level (components, content, lib) provide additional UI components, content assets, and library code that the root files and feature directories consume. Together, the root entry files initialize the app and styles, while feature subdirectories like office/ encapsulate domain-specific UI and tests used by the rest of the application.


### File Organization

Root-level files provide application entry and global styles; feature-specific code is grouped into subdirectories (for example office/) that contain components, domain logic, and tests. This keeps app bootstrap and styling at the root while isolating feature implementations under their own folders for clarity.
