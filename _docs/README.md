## Overview

This repository root contains configuration and entry points for project-level behavior and testing. At the root there is a vitest.config.js file which defines the Vitest configuration for the project; this file centralizes test runner settings and is the primary configuration file for running the test suite. In addition, there are a number of project files and assets present at the root (listed under "ALSO IN THIS DIRECTORY") such as package.json and various HTML and image assets which support the broader project, but whose specific purposes are not detailed here.

Two important subdirectories are present. The tests/ directory holds test specifications (a single Vitest test file, fajer-parsa.test.js) used to verify behavior and regressions of related code. The web-v2/ directory is a top-level application directory that groups frontend source, server implementations, and project-level configuration and deployment files for the web-v2 application; it is described as the web-v2 application repository root and contains its own build and project configuration. Together, the vitest.config.js at the root and the tests/ specifications provide the testing infrastructure, while web-v2/ groups the main application code and configuration that the tests and CI would exercise.


### File Organization

Root-level configuration (vitest.config.js and package/project files) sits at the repository root. Tests are grouped under tests/ and target code in the repository (including the web-v2 application). The web-v2/ directory encapsulates the application-specific source, server code, and its project configuration separate from root-level test configuration to keep application code and test/configuration concerns separated.
