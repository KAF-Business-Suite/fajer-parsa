## Overview

This repository root holds configuration and test orchestration files along with several top-level application and asset directories. At the root there is a Vitest configuration file (vitest.config.js) that defines how test suites are discovered and run. In addition, the root contains a number of static files and repository-level metadata (for example: .gitignore, README.md, package.json, package-lock.json) and several image and HTML preview files which serve as static assets and previews for the project.

Two purpose-specific subdirectories are present and organize the codebase further. The tests/ directory contains Vitest test specifications (a single root-level test file, fajer-parsa.test.js) used to verify code behavior and guard against regressions. The web-v2/ directory groups the web-v2 application code and build/configuration files (frontend, server request handlers, and supporting config and build files) necessary to build and run that application. Together, the root-level config (notably vitest.config.js), the tests directory, and the web-v2 application directory form the coordination point for development workflows: configuration and test setup live at the root while implementation and test specs live in their respective subdirectories.


### File Organization

Top-level includes configuration and static assets; behavior verification lives under tests/ and application source and build files live under web-v2/. The vitest.config.js at the root centralizes test configuration so test discovery and execution operate across the repository's code and test specifications.
