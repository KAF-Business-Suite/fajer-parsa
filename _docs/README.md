## Overview

This directory contains the Vitest configuration for the project at the root and a dedicated tests subdirectory that holds the Vitest test specifications. At the root, vitest.config.js defines how Vitest runs for this repository (test environment, match patterns, reporters, and other runner options). That file is the single source of test-run configuration and is intended to be consulted and updated when test-run behavior needs to change.

The tests/ subdirectory contains test specification files used to verify behavior and prevent regressions. Specifically, there is one test specification at the root of tests/ named fajer-parsa.test.js which defines test cases and assertions that exercise the codebase components targeted by the tests. Together, vitest.config.js and tests/ provide a focused testing surface: configuration at the top-level governs how tests run while tests/ contains the actual test cases executed by that configuration. This directory therefore serves as the testing entry point and documentation surface for test-related setup in the repository.


### File Organization

Root holds test runner configuration (vitest.config.js). A single subdirectory named tests/ groups all test specifications (currently one test file). This keeps configuration separate from test content and makes it clear where to update runner settings versus test cases.
