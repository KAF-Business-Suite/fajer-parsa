# فجرپارسا: آزمون رایگان، بی‌نیاز از TestDriver

## چرا تغییر؟
گزارش Run 40954168123 در ۲۹ اکتوبر ۲۰۲۶ نشان داد TestDriver با پیام «۳۰ دقیقهٔ رایگان تمام شده است» متوقف شده. دستور کلی `vitest run` فایل‌های Node Test را نیز به‌اشتباه تشخیص داده بود. فایل `tests/fajer-parsa.test.js` هنوز سایت قدیمی GitHub Pages و عناصر یک فرم قدیمی را هدف می‌گیرد، نه Production فعلی Cloudflare.

## اصلاح پیشنهادی (فقط Draft؛ بدون انتشار)
- TestDriver دیگر با هر Push/PR اجرا نمی‌شود؛ فقط با درخواست دستی و تا زمانی که سهمیه اجازه دهد.
- دستور اجرای دستی آن فقط همان سناریوی قدیمی را هدف می‌گیرد. **نتیجهٔ آن معیار پذیرش سایت فعلی نیست.**
- آزمون رایگان GitHub Actions با Node و Chromium خود پروژه اجرا می‌شود: تست‌های مشتری/سرور، Build سایت، بررسی نمایشی با ۴۱ سناریوی محلی و فرم آزمایشی با پاسخ‌های شبیه‌سازی‌شده.
- هر Test fail سبب شکست همان آزمون می‌شود؛ هیچ Fail به PASS تبدیل نمی‌شود.
- هیچ پرداخت، نشر، تذکره، مشتری، دیتابیس زنده، رمز یا پیام WhatsApp در این تست‌ها استفاده نمی‌شود.

## تعبیر ساده
- سبزشدن این CI یعنی «کد با نمونه‌های ساختگی و مرورگر خودکار کار می‌کند».
- این **به معنی** فعال‌شدن سایت زنده، وصل‌شدن دیتابیس مشتری، ورود کارمندان یا موفقیت آزمون Samsung واقعی نیست.

## ترتیب
1. PR این تغییرات را بررسی کنید؛ تا قبل از Merge، سایت اصلی عوض نمی‌شود.
2. اول هماهنگی نسخهٔ اصلی در PR #6 تکمیل شود.
3. اگر CI و مرور این PR سبز شد، آن را همراه اصلاحات مربوط به نسخهٔ اصلی وارد `main` کنید.
4. PR #8 برای نشر امن و همیشه‌روشن همچنان Draft و مستقل است.
